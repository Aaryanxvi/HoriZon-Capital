Run it in Your Terminal

Prefer the command line? Clone the repo and start the agent in one line. Needs Python 3.11+. Everything is stored in a local SQLite file, with no database or servers to set up. Starts in paper trading mode.

$ git clone https://github.com/Aaryanxvi/HoriZon-Capital && cd HoriZon-Capital/backend && pip install -r requirements.txt && python -m app
CIO_MODE=AI horizon-terminal
Architecture

Institutional-Grade Intelligence.
Running on Your Machine.

Every department of a quantitative hedge fund (finding trades, managing risk, keeping the books) rebuilt as AI agents that work together in real time.

Alpha Generation

Front Office

A team of strategy agents reads the market: HMM regime detection spots whether conditions are calm or turbulent, FinBERT scores news sentiment, and technical signal generators propose trades for the rest of the firm to review.

HMM Regime Detection FinBERT NLP Signal Ensemble

Middle Office

Every order is checked against position, drawdown and Value-at-Risk limits. A kill switch stops trading the moment a limit is breached.

VaR Limits Kill Switch

Back Office

Records every fill, cash balance and NAV update in a local SQLite database, so every decision stays on your machine and can be audited.

SQLite NAV Engine
Core Differentiator

Multi-Agent Debate Engine

No single model trades alone. Every signal is argued from four angles (strategy, risk, sentiment and portfolio) by competing AI models such as GPT, Claude and Gemini. A trade goes through only if their confidence-weighted vote clears the approval bar.

4 Specialist Roles Multi-Model Debate Weighted Consensus

The Executive Layer

You choose who has the final say: Human-in-the-Loop, where you approve or reject every trade, or an Autonomous AI CIO that runs the portfolio hands-free. Switch at any time.
